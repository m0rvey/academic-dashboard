## ✨ Основные возможности

- 📋 **Управление задачами и дедлайнами** — Полный цикл CRUD операций, приоритеты, сложность (1–10), теги (`#ОГЭ`, `#ЕГЭ`, `#ДЗ`) и статусы (`TODO`, `DOING`, `DONE`).
- 🗂️ **Два режима отображения** — Переключение в 1 клик между структурированным списком с группировкой по срочности и интерактивной **3-колоночной Канбан-доской**.
- ⚡ **Динамическая приоритезация** — Аналитический расчёт приоритета: наверх поднимаются горящие сроки, высокая сложность и экзаменационные теги.
- 🍩 **Современная аналитика** — Donut-диаграмма распределения нагрузки по дисциплинам с индикатором в центре, 7-дневный график завершённых задач и радар тегов.
- 🎯 **GPA и калькулятор целей** — Точный расчёт GPA и аналитический калькулятор пятерок без перебора $O(1)$ («Сколько пятёрок нужно до балла 4.75»).
- 🌓 **Динамические темы (Dark / Light)** — Глубокий обсидиановый тёмный режим Deep Slate (`#0B0F19`) и чистый светлый режим (`#FFFFFF`).
- 🤖 **Telegram-бот с удобной нумерацией** — Порядковая нумерация задач `1.`, `2.`, быстрые действия `[⚡ #1 В процесс]`, `[✅ #1 Готово]` и умный `/done`.
- 🔄 **Реактивная синхронизация** — Мгновенное обновление данных между ботом и GUI-приложением через SQLite WAL и файловый наблюдатель.
- 💻 **Консольный режим CLI** — Автономная работа в терминале без GUI.

## 🤖 Telegram-бот

Бот на **Aiogram 3** оптимизирован для быстрого управления со смартфона:

- **Человекопонятная нумерация**: Задачи нумеруются по порядку приоритета `1.`, `2.`.
- **Быстрый `/done`**:
  - `/done` — выводит интерактивную инлайн-клавиатуру со списком задач для завершения в один клик.
  - `/done 1` — завершает задачу под номером 1.
- **Команды бота**:
  | Команда | Описание |
  | :--- | :--- |
  | `/start`, `/help` | Приветствие и полный справочник команд |
  | `/list` | Интерактивный список активных задач с кнопками действий |
  | `/done [N]` | Завершение задачи (в 1 клик или по номеру) |
  | `/load` | Проверка дневной нагрузки и лимита |
  | `/stats` | Сводка KPI, распределение предметов и тегов |
  | `/grades` | Средний балл (GPA) и статистика оценок 5/4/3/2 |
  | `/add [текст]` | Создание задачи через NLP-парсинг или диалог |
  | `/settings` | Выбор времени ежедневной утренней сводки |
  | `/backup` | Выгрузка дампа базы данных (для администраторов) |
  | `/cancel` | Отмена активного создания задачи |

## 🧮 Математические модели и алгоритмы

### 1. Формула динамического приоритета
$$\text{Priority} = \frac{\text{effort\_score}}{\max(0, \text{days\_left}) + 1} \times M_{\text{exam}}$$
- $\text{days\_left} = \text{deadline} - \text{today}$
- $M_{\text{exam}} = 1.5$, если задача содержит теги `ОГЭ`, `ЕГЭ` или `Экзамен` (иначе $1.0$).

### 2. Аналитический калькулятор GPA ($O(1)$)
$$k = \left\lceil \frac{T \cdot N - S}{5 - T} \right\rceil$$
- $N$ — текущее количество оценок, $S$ — сумма всех оценок, $T$ — целевой балл GPA.

## 🗣️ NLP-парсер русского языка

Бот и GUI поддерживают добавление задач фразами на естественном языке:
> *"Запиши домашку по физике лаба 3 на завтра сложность 4 #ОГЭ"*

Парсер автоматически извлекает:
- 📚 **Предмет**: `Физика` (по корню слова или синонимам)
- 📝 **Описание**: `Лаба 3`
- 📅 **Дедлайн**: `2026-08-15` (поддерживает *«завтра»*, *«через 3 дня»*, *«в пятницу»*, даты `ГГГГ-ММ-ДД`)
- 💪 **Сложность**: `4` (из ключевых слов *«сложность 4»* или отдельно стоящих чисел)
- 🏷️ **Теги**: `["ОГЭ"]` (из хештегов `#` или ключевых слов)

## 🚀 Быстрый запуск

### Требования
- Python **3.10+** (поддерживаются 3.10, 3.11, 3.12)
- macOS, Linux или Windows

### Установка

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/m0rvey/academic-dashboard.git
   cd academic-dashboard
   ```

2. **Создайте и активируйте виртуальное окружение**:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate  # На Windows: .venv\Scripts\activate
   ```

3. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```

### Настройка `.env`

Создайте файл `.env` в корне проекта (или скопируйте из шаблона):
```bash
cp .env.example .env
```

Заполните параметры в `.env`:
```ini
# Telegram Bot Token (получить у @BotFather)
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz

# Telegram Chat ID разрешенных пользователей (через запятую, узнать у @userinfobot)
TELEGRAM_ALLOWED_USERS=123456789

# Telegram Chat ID администраторов бота (опционально)
TELEGRAM_ADMIN_USERS=123456789
```

4. **Запустите приложение**:
   ```bash
   # Запуск GUI (вместе с фоновым Telegram-ботом)
   python main.py

   # Или запуск только в консольном режиме (CLI)
   python main.py --cli

   # Или запуск только Telegram-бота (автономный режим)
   python bot.py
   ```

## ⌨️ Горячие клавиши (macOS Shortcuts)

| Сочетание | Действие |
| :--- | :--- |
| <kbd>Cmd</kbd> + <kbd>N</kbd> | Добавить новую задачу |
| <kbd>Cmd</kbd> + <kbd>F</kbd> | Быстрый фокус на строке поиска |
| <kbd>Cmd</kbd> + <kbd>R</kbd> | Принудительное обновление данных |
| <kbd>Cmd</kbd> + <kbd>T</kbd> | Переключение темы (Тёмная / Светлая) |
| <kbd>Cmd</kbd> + <kbd>B</kbd> | Запустить или перезапустить Telegram-бота |
| <kbd>Cmd</kbd> + <kbd>/</kbd> | Открыть справку по горячим клавишам |
| <kbd>1</kbd> .. <kbd>4</kbd> | Переключение между вкладками |
