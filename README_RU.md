## ✨ Основные возможности

- 📝 **Управление задачами (CRUD)** — Предмет, описание, дедлайн, сложность (от 1 до 10), теги и статусы (Сделать / В процессе / Готово).
- ⚡ **Умная приоритезация** — Динамический расчёт приоритета: в первую очередь выставляются горящие дедлайны, высокие трудозатраты и экзаменационные предметы (ОГЭ / ЕГЭ / Экзамен).
- 📊 **Контроль дневной нагрузки** — Дневной лимит (рекомендуется 10 ед. сложности) с визуальным индикатором и предупреждениями о перегрузке.
- 🎯 **GPA и прогнозирование оценок** — Аналитический алгоритм \(O(1)\) без итераций, вычисляющий exact число пятерок для достижения желаемого среднего балла.
- 🗣️ **NLP-парсер русского языка** — Быстрый ввод задач фразами на естественном языке (например, `"домашка по физике лаба 3 на завтра сложность 4 ОГЭ"`).
- 🖥️ **4-вкладочный настольный GUI** — Разработан на Flet (движок Flutter для Python) с поддержкой тёмной/светлой темы, импортом/экспортом JSON и отслеживанием файлов БД в реальном времени.
- 🤖 **Функциональный Telegram-бот** — Бот на Aiogram 3 с FSM-созданием задач, защиты от спама (RateLimit middleware), авторизацией пользователей, ежедневными автоматическими напоминаниями и бэкапами.
- 💻 **Консольный режим CLI** — Полноценный терминальный интерфейс для серверов или слабых ПК.

## 🏗️ Архитектура системы

Проект спроектирован по принципам слабой связности (Decoupling) и разделения ответственности по слоям:

```
academic-dashboard/
├── main.py                  # Главная точка входа (запуск GUI или CLI)
├── bot.py                   # Запуск процесса и потока Telegram-бота
├── pyproject.toml           # Метаданные и конфигурация линтера (Ruff)
├── requirements.txt         # Зависимости проекта
├── data/                    # База данных SQLite и лог-файлы
├── src/
│   ├── core/                # Бизнес-логика, математические модели и слой БД
│   │   ├── config.py        # Глобальные конфигурационные константы
│   │   ├── interfaces.py    # Абстрактный интерфейс IDatabaseManager
│   │   ├── logic.py         # Алгоритмы приоритезации и расчёта GPA
│   │   ├── models.py        # Pydantic-модель Task и Enum статусов
│   │   ├── nlp_parser.py    # Модуль разбора фразового ввода на русском языке
│   │   ├── migrations.py    # Миграции схемы базы данных SQLite
│   │   └── database/        # Слой репозиториев (Repository Pattern)
│   │       ├── connection.py        # Менеджер подключения SQLite (WAL mode, Foreign Keys)
│   │       ├── task_repository.py   # CRUD задач, тегов, фильтрация и SQL-сортировка
│   │       ├── grade_repository.py  # Статистика оценок и средний балл по предметам
│   │       ├── stats_repository.py  # Метрики KPI и распределение нагрузки за 7 дней
│   │       ├── backup_manager.py    # Экспорт/импорт JSON и ротация бэкапов
│   │       ├── user_repository.py   # Хранилище зарегистрированных пользователей бота

│   │   ├── components/      # Компоненты (карточки KPI, задач, уведомления macOS)
│   │   ├── dialogs/         # Диалоговые окна (добавление/редактирование, удаление)
│   │   ├── tabs/            # Вкладки (Задачи, Статистика, Успеваемость, Календарь)
│   │   └── views/           # Экраны (Дашборд, Консоль логов)

│   └── bot/                 # Модуль Telegram-бота на Aiogram 3
│       ├── dependencies.py  # Инициализация бота и конфигурации
│       ├── scheduler.py     # Фоновая служба ежедневных напоминаний
```

## 🧮 Математические формулы и логика

### Умный приоритет задач (Smart Priority)

Приоритет каждой задачи \(P\) вычисляется динамически по формуле:

$$P = \frac{\text{effort\_score}}{\text{days\_left} + 1} \times \text{exam\_multiplier}$$

Где:
- **`effort_score`**: Оценка сложности задачи от $1$ (Очень легко) до $10$ (Экстремально).
- **`days_left`**: Количество дней до дедлайна ($\max(0, \text{deadline} - \text{today})$).
- **`exam_multiplier`**: Равен $1.5$, если задача содержит экзаменационные теги (`ОГЭ`, `ЕГЭ`, `Экзамен`), иначе $1.0$.

### GPA и калькулятор целевых оценок

Для достижения желаемого среднего балла $G_{\text{target}}$ при наличии $N$ текущих оценок с суммой $S$, система вычисляет минимально необходимое количество пятерок ($K_5$) в аналитическом виде $O(1)$:

$$K_5 = \left\lceil \frac{G_{\text{target}} \cdot N - S}{5 - G_{\text{target}}} \right\rceil$$

## 🗣️ NLP-парсер естественного языка

Встроенный парсер русского языка конвертирует произвольный текст в валидный объект `Task`:

```text
Ввод:   "домашка по физике лаба 3 на завтра сложность 4 ОГЭ"
Результат: Предмет = "Физика"
           Описание = "Лаба 3"
           Дедлайн = дата завтрашнего дня (YYYY-MM-DD)
           Сложность = 4
           Теги = ["ОГЭ"]
```

Возможности разбора:
- **Относительные даты**: `"сегодня"`, `"завтра"`, `"послезавтра"`, `"через 3 дня"`.
- **Распознавание предметов**: Школьные предметы и сленговые сокращения (`маша`/`математика`, `физра`, `обж`, `лит-ра`).
- **Извлечение сложности**: Числа после ключевых слов `"сложность"`, `"сложность:"`, `"уровень"`.

## 🚀 Быстрый запуск

### Требования

- **Python ≥3.10**
- **Git**

### Установка

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/m0rvey/academic-dashboard.git
   cd academic-dashboard
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate  # Windows: .venv\Scripts\activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt pytest pytest-asyncio ruff
   ```

### Переменные окружения (`.env`)

Создайте файл `.env` в корневой директории:

```env
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
TELEGRAM_ALLOWED_USERS=123456789
TELEGRAM_ADMIN_USERS=123456789
# Настройки прокси при необходимости:
# TELEGRAM_PROXY=socks5://username:password@ip:port
# TELEGRAM_API_SERVER=https://tg-proxy-worker.username.workers.dev
```

## 💻 Режимы работы

### 1. Графический интерфейс (GUI)

Запуск графического приложения:

```bash
.venv/bin/python main.py
```

Особенности:
- **Задачи**: Фильтрация по статусам и тегам, поиск, сортировка по приоритету/дедлайну, быстрая отметка выполнения.
- **Статистика**: Графики нагрузки по предметам, динамика выполнения за 7 дней и KPI.
- **Успеваемость**: Распределение оценок, текущий GPA по предметам, расчёт необходимых оценок.
- **Календарь**: Сетка месяца с запланированными задачами.
- **Консоль отладки**: Клик по значку статуса Telegram-бота открывает онлайн-логи приложения.

### 2. Консольный режим (CLI)

Запуск терминального меню:

```bash
.venv/bin/python main.py --cli
```

Интерактивное консольное меню для добавления задач, просмотра списков по приоритету и управления статусами.

### 3. Telegram-бот

Отдельный запуск Telegram-бота:

```bash
.venv/bin/python bot.py
```

Доступные команды бота:
- `/start` — Регистрация и приветствие.
- `/add` — Пошаговый FSM-диалог создания задачи.
- `/list` — Список активных задач, отсортированный по приоритету с кнопками быстрых действий.
- `/stats` — Дашборд KPI-статистики.
- `/grades` — Сводка успеваемости и средний балл GPA.
- `/load` — Нагрузка на сегодня в сравнении с дневным лимитом.
- `/backup` — Получение JSON бэкапа базы данных (только для админа).
- `/cancel` — Отмена текущей операции.
